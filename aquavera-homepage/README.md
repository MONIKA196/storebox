# AQUAVERA — Wastewater Treatment Homepage

A responsive, animated homepage concept for a fictional wastewater treatment and water reuse company.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code + Live Server.
3. The site uses Google Fonts and remote Unsplash images, so an internet connection is needed for those assets.

## Deploy (Netlify)
1. Open https://app.netlify.com/drop
2. Sign in, then drag the extracted `aquavera-homepage` folder into the deploy area (if your browser asks, zip the folder and upload the ZIP).
3. Wait for the deployment to finish and copy the live URL.

## Deploy (Vercel)
1. Create a GitHub repository and upload `index.html`, `style.css`, and `script.js`.
2. Go to https://vercel.com/new, import that repository, and deploy it as a static site.
3. Copy the live deployment URL.

## Before submitting
- Test desktop and mobile widths.
- Click every navigation link and solution card.
- Test the form with valid and invalid values.
- Confirm the live URL opens in an incognito/private window.
- Submit only the live URL at https://forms.gle/JjF2DheGAWga9jYf8

## Important honesty note
The enquiry form is a front-end prototype. It validates input and shows a confirmation message locally, but does not send submissions to a server. The company, impact statements, and metrics are illustrative concept content, not verified real-world claims.
